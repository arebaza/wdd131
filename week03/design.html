Web Design Principles

WDD 131 – Week 03 Assignment

Contrast

Contrast helps users see what is important. High contrast improves readability and accessibility by clearly separating content.

Alignment

Alignment creates visual order and organization. When elements line up, the page feels clean and professional.

Proximity

Proximity groups related elements together so users can understand relationships between content quickly.

Repetition

Repetition builds consistency. Using the same styles, colors, and layout helps users feel comfortable navigating the page.

Visual Hierarchy

Hierarchy shows importance using size, color, and spacing. Headings stand out, guiding users through the content.
